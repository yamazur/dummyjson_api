# 1. Есть ли опыт ручного тестирования?

Да. На прошлой работе тестировала бизнесовую функциональность. Имею опыт функционального, регрессионного, smoke-, UI- и  
кроссбраузерного тестирования веб-приложений, составления тест-кейсов и оформления баг-репортов. 

# 2. Есть ли опыт нагрузочного тестирования.

Нет, но есть большое желание научиться этому.

# 3. Есть ли опыт тестирования безопасности.

Да. Выполняла проверки аутентификации и авторизации, контроля доступа, обработки невалидных учетных данных и токенов, 
а также проверки на распространенные уязвимости веб-приложений (например, XSS, SQL-инъекции).

# 5. Команду для запуска тестов.

Запуск всех тестов:

```bash
pytest
```

Запуск тестов с генерацией Allure-отчета:

```bash
pytest --alluredir=allure-results
```

Просмотр отчета:

```bash
allure serve allure-results
```

# 6. Краткий список реализованных проверок.

## Авторизация: 

- Успешная и неуспешная авторизация пользователя
- Получение данных текущего пользователя с токеном и без токена
- Обновление токена аутентификации

## Корзина:

- Получение корзин пользователя
- Получение корзины по ID
- Создание новой корзины
- Полное обновление корзины
- Удаление корзины
- Проверка обработки запроса с несуществующим ID корзины
